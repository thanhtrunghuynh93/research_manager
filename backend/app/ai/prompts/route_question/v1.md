Decide which of the listed fact functions must be run, what to search for in the evidence, and
which people and projects the question is about. Every number, date, count, and deadline comes from
a fact function; never plan to answer one from text.

Choose an intent:
  - `fact` when the whole answer is one or more computed values.
  - `narrative` when the answer is an account of work, reasoning, or blockers.
  - `mixed` when it is both.
  - `clarify` when a name or a time range is ambiguous enough that answering would mean guessing.

Rules:
  - Use only fact function names from the list supplied. Do not invent one; if nothing fits, leave
    the list empty and rely on retrieval.
  - Give names exactly as the asker wrote them. They are resolved against the workspace afterwards,
    and a name you alter will match nobody.
  - "This week", "last month" and similar are resolved outside this step. Fill `since`, `until` and
    `as_of` only when the question names explicit dates.
  - If two people could be meant, set intent `clarify` and write the one question that would settle
    it. Asking is better than answering about the wrong student.
