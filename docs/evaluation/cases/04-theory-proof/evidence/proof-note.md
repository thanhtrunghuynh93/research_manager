Theorem 3.1 (projected variant). Let C be closed and convex, gradients bounded by G, step size
eta_t = c/sqrt(t). Then E[f(x_T) - f*] <= 2 G^2 (1 + log T) / (c sqrt(T)).
Remark: the constant is twice that of Theorem 2.4 (unprojected); the draft of 7 September stated
they were equal, which was an error.
